
Immediate Steps for any emergency according to the situation:
 Lock down all entry and exit gates immediately.
 Alert on-site security personnel.
 Notify local law enforcement authorities.
 Activate emergency alarm system.
 Initiate CCTV recording lockdown mode.
 Evacuate civilians from nearby area.
 Maintain communication with central control room.
 Dispatch security personnel for verification.
 Monitor suspect via CCTV.
 Inform shift supervisor.
 Prepare escalation protocol if threat increases.
